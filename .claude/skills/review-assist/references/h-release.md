# H 關卡：上版核准

這是進入 main 之前最後一次人工確認。重點是**整體一致性**，不是重新審一次程式碼。

## 要讀的東西

1. Jira 單的完整歷程（所有備註）
2. 分支上的 ChangeLog 片段：`changes/<單號>.md`
3. PR 的 `view` 與 `checks`

## 檢查項目

### 流程完整
- 經過 B 關卡的規格確認
- 經過 F 關卡的審查，且之後沒有新的程式碼變更（若 F 之後又有 commit，需要重新審查）
- CI 檢查全部通過

### ChangeLog
- 內容正確描述這次的變更，使用者看得懂
- 變更類型正確（新功能／修正／破壞性變更），這會影響版號
- 破壞性變更有說明影響與因應方式

### 相依關係
- 如果這張單「被其他單阻擋」，確認那些單已發版或會在同一批先上版
- 如果有其他單依賴這張單，提醒使用者

### 時機
- 提醒使用者確認這次上版的時機沒有問題（例如是否避開活動期間），這部分由使用者判斷
